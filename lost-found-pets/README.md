
# Lost & Found Pets (React)

This is a simple React.js project that implements a Lost & Found Pets website prototype.

## Features
- Landing page with hero, recent lost/found pets, testimonials and about section.
- Report Lost Pet form and Report Found Pet form.
- Conditional fields (breed, color-other, size-other).
- Client-side validation (required fields, 10-digit contact).
- Data stored in localStorage.
- Responsive layout.

## How to run locally

1. Ensure Node.js >= 16 and npm installed.
2. In the project folder, run:
   ```
   npm install
   npm start
   ```
3. Build for production:
   ```
   npm run build
   ```

## Deploying
Push to GitHub and connect to Netlify (import from GitHub), build command `npm run build`, publish directory `build`.
